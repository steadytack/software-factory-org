## Preferences {#profile-prefs}
<!-- keywords: profile, display name, landing page, preferences, density, table, rows, wrap, freeze, password -->

Set a **display name** (shown in the header instead of your email) and a **landing page** (where you land after signing in). Under **Display**: interface density (Compact for mouse and keyboard, Comfortable for touch); table rows (Dense, Standard or Roomy), wrap text and freeze first column, used by every table (the gear on a table changes the same settings). With several users, you can also change your password here. Preferences are stored in this browser.
