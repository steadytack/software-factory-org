## Adding a site {#sites-add}
<!-- keywords: add, create, new site, dialog -->

Click **Add site** (or press `N`). A name and a location are required: click the map or drag the pin, or type an easting and northing; the address and postcode follow the pin. New sites appear in the table straight away, even offline.

## Saved views {#sites-views}
<!-- keywords: views, bookmark, filter, save, layout -->

The bookmark button saves the current filter, sorting, column visibility, column order and widths under a name. Views are stored in this browser and can be applied or deleted from the same menu.

## CSV export {#sites-csv}
<!-- keywords: csv, export, download, excel -->

The export button (or “Export … as CSV” in the Ctrl K palette) downloads the *filtered* rows as CSV — apply a filter first to export a subset.
