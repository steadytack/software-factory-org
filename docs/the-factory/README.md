# The factory, assessed by the factory

The software factory, put through its own first stage as if it were an idea: a brief, an assessment and a sponsor overview, in the same formats every idea gets (`factory/project-files/`). It explains what the factory does, how it works and what impact it should have, and it shows the formats people will see for their own ideas.

| Document | For | Format |
|---|---|---|
| [overview.md](overview.md) | Sponsors and leaders: the case, the impact and the decision asked, in plain language | The sponsor overview, shown at Gate 1 |
| [idea-brief.md](idea-brief.md) | Anyone who wants the detail: the problem, the outcome, how it works, the risks, the people | The idea brief |
| [assessment.md](assessment.md) | Anyone who wants to test the case: the five foundations, the priority score, a pre-mortem and the recommendation | The assessment |

Every assumption is marked *(assumed)*. Replace each with a figure from your own organisation where you have one; that is exactly what the factory asks of any idea.
