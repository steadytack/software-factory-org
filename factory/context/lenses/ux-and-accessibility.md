# Lens: UX and accessibility

**Activate:** when there is a visual interface.

- Brand (personal, organisation, existing product, unbranded), design system (an approved catalogue design asset or a lightweight new one) and interaction style (dashboard, forms, tables, map, timeline, chat). Infer the visual direction from these; ask only if materially ambiguous.
- What are the screens and how do they connect? What are the empty, loading, success, validation and error states?
- Does it work on a phone? Can it be used by keyboard? Which accessibility level fits the tier and audience (DEF-08)?
